Help

Getting Started

  1. Use Tasks for actions, Events for date-based commitments, Notes for reference, and Activity for a lightweight work log.
  2. On mobile, use Today to access the existing Planner.
  3. Use the workspace tabs to switch between Calendar, Tasks, Notes, Events, and Activity.

Tasks

  • Create Tasks in Inbox, Today, This month, or Someday.
  • Use status, highlight, tags, next action, and optional date/time scheduling.
  • Link a Task to a new or existing Note.
  • Archive completed Tasks and restore them later if needed.

Events

  • Create one-time or recurring Events with an optional time, duration, tag, highlight, and next action.
  • Timed Events can appear in the Planner.
  • Create a Note or link an existing Note to an Event.

Notes

  • Select a compact Note row to open it. Use the star to pin or unpin it.
  • Use Labels to organise and filter Notes.
  • Use Link Note to connect Notes. Links appear under Related Notes.
  • Use Edit for writing and formatting, including bullets, numbering, checklists, and horizontal lines.

Voice Capture

  • On mobile, open More, then Voice Capture.
  • Use the keyboard microphone or type, then save as a Task, Event, Note, or Activity.

Planner

  • Select an empty timeblock to add a Task, Event, or Activity.
  • Use the status control to mark a block as Planned, In progress, or Done.

Backup & Privacy

  • Export regularly to create a complete local backup. Use Import to restore it.
  • Data is stored locally on the current device. No account is required.
Install FAST GTD as a PWA for an app-like experience. Local data is specific to the browser or installed app, so keep regular exports.

Quick Start

  • + Task saves a new Task to Inbox.
  • + Note opens simple capture with Labels and Link Note visible.
  • + Event creates a date-based commitment.

Navigation

  • Today opens the daily Planner.
  • Tasks opens Inbox, Today, This month, and Someday.
  • Notes opens all Notes and Label filtering.
  • More opens Activity, Events, Calendar, Voice Capture, Export, Import, Help, and Share.

Voice Capture

  • Open More, then Voice Capture.
  • Use the keyboard microphone or type.
  • Save as Task, Event, Note, or Activity.

Notes

  • Tap a compact Note row to open it.
  • Tap ★ to pin or unpin.
  • Use Link Note to connect Notes.
  • Linked Notes appear under Related Notes.

Planner

  • Tap an empty timeblock.
  • Add a Task, Event, or Activity.
  • Update status directly from the Planner.

Backup

  • Export creates a backup.
  • Import restores a backup.
  • Data stays on your device.
